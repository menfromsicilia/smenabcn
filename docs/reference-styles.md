# Стили референса «Anna» (Row Creative)

Источник: демо шаблона `https://dove-gecko-cs7n.squarespace.com` (пароль демо опубликован на странице товара).
Сняты через `getComputedStyle` на 1440×900 и 390×844, дата: 2026-10-26.

## Шрифты

| Роль | Референс | Наше решение | Почему |
|---|---|---|---|
| Заголовки | **Instrument Serif**, weight 100 (рендерится как 400), `uppercase`, `letter-spacing: -0.03em` | **Playfair Display Variable**, 400, `uppercase`, `-0.03em` | у Instrument Serif нет кириллицы; Playfair — ближайшая контрастная антиква с полной кириллицей (і ї є ґ) |
| Акцент в заголовке | `<em>` Instrument Serif italic, **без** uppercase | Playfair Display italic, без uppercase, цвет акцента | так же, как в референсе: «BUILD *the* BUSINESS» |
| Текст | **Montserrat** 400, `letter-spacing: -0.02em` | **Montserrat Variable** | есть кириллица, совпадает с референсом |
| Кнопки | Roboto 500, 14 px, uppercase, `-0.02em` | Montserrat 600, 14–15 px, uppercase, `0.02em` | один гротеск на всё, вес чуть выше ради читаемости кириллицы |
| Навигация | Montserrat 400, 14 px, uppercase, `-0.06em` | Montserrat 500, 13 px, uppercase, `0.04em` | кириллица в капсе с отрицательным трекингом слипается |

## Цвета

| Референс | Значение | Наш токен |
|---|---|---|
| Фон страницы | `#F3F2EE` (нейтральный крем) | `--bg` → **#F3F2EE** (вместо #F6F0E6) |
| Основной текст / тёмные секции | `#272519` | `--ink` остаётся **#1C1A17**: с #272519 томатный фон даёт 4.26:1 < AA |
| Акцентная жёлтая | `#FFFFA5` (кнопки, секции, текст на синем) | `--butter` → **#FFF7A0** (чуть теплее, контраст с ink 17:1) |
| Синий (хедер, футер) | `#4384E8` | `--sky` → только детали и акценты: точки eyebrow, звёзды бегущей строки, иконки фактов, галочки формы, номер карточки «Администраторы», заголовки колонок футера. Текст на нём только `--ink` (4.7:1, AA); крем (3.4:1) и жёлтый — только для крупных заголовков |
| Чёрный (hero) | `#000` | hero у нас светлый (коллаж), чёрный — только футер (`--ink`) |

Палитра направлений из ТЗ (tomato/butter/blush) сохраняется: это смысловая раскраска карточек. Секция «Как работаем» — на `--blush` (вместо `--olive` из ТЗ), футер — `--ink`, `--sky` только акцентами.

## Компоненты

- **Кнопка:** пилюля `border-radius: 300px`, высота 50, padding `16.8px 15.4px`, без обводки, uppercase. Hover: `opacity` 0.1s. → у нас 56/52 px (touch-target), hover по ТЗ: `translateY(-2px)` + смещение стрелки.
- **Хедер:** sticky, 83 px, цветной фон, лого слева, навигация uppercase справа, кнопка-пилюля в конце.
- **Секции:** full-bleed цветные плашки без внутренних радиусов, чередование крем → тёмный → жёлтый → крем → синий.
- **Фото:** прямоугольные, без радиусов и поворотов (у нас по ТЗ: скругления + поворот 2–4°, это сознательное отличие под «полароидный» мотив).
- **Marquee:** огромный текст Instrument Serif (221 px) на фоне секции. У нас — полоса 64 px по ТЗ.
- **Футер:** огромный wordmark на всю ширину (≈20vw), под ним колонки «Explore / Contact», ссылки подчёркнуты.
- **Анимации:** классы `preSlide → slideIn` и `preFade → fadeIn` (сдвиг + прозрачность при скролле), картинки с параллаксом `translateY`.
